# tree-sitter-fitd

Tree-sitter grammar for `.fitd` sources, with highlight queries for Neovim (`queries/highlights.scm`) and Helix (`queries/helix/highlights.scm`, same rules in Helix's capture names). `src/` is generated by `tree-sitter generate` (CLI 0.26.9) and committed, so editors build the parser without Node.

Check after editing `grammar.js`:

```sh
tree-sitter generate && tree-sitter test -p .
tree-sitter parse -p . -q ../../examples/*.fitd   # prints nothing when every file parses
```

## Neovim (0.11+)

No plugin needed: build the parser into the runtime path and start highlighting on the filetype.

```sh
cc -shared -fPIC -O2 -I src src/parser.c -o ~/.local/share/nvim/site/parser/fitd.so
mkdir -p ~/.local/share/nvim/site/queries/fitd
cp queries/highlights.scm ~/.local/share/nvim/site/queries/fitd/
```

```lua
vim.filetype.add({ extension = { fitd = 'fitd' } })
vim.api.nvim_create_autocmd('FileType', { pattern = 'fitd', callback = function() vim.treesitter.start() end })
vim.lsp.config('fitd', { cmd = { 'fitd', 'lsp' }, filetypes = { 'fitd' }, root_markers = { '.git' } })
vim.lsp.enable('fitd')
```

## Helix

In `~/.config/helix/languages.toml`, with the path pointing at this directory:

```toml
[[language]]
name = "fitd"
scope = "source.fitd"
file-types = ["fitd"]
comment-token = "#"
indent = { tab-width = 2, unit = "  " }
language-servers = ["fitd"]

[language-server.fitd]
command = "fitd"
args = ["lsp"]

[[grammar]]
name = "fitd"
source = { path = "/path/to/fitd/editors/tree-sitter-fitd" }
```

Then `hx --grammar build` and copy `queries/helix/highlights.scm` to `~/.config/helix/runtime/queries/fitd/highlights.scm`.
