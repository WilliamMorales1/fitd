# tree-sitter-fitd

Tree-sitter grammar for `.fitd` sources, with highlight queries for Neovim (`queries/highlights.scm`) and Helix (`queries/helix/highlights.scm`, same rules in Helix's capture names). Both editors let a later pattern override an earlier one, so the catch-all `(name) @variable` stays at the top of each file. `src/` is generated by `tree-sitter generate` (CLI 0.26.9) and committed, so editors build the parser without Node.

Check after editing `grammar.js`:

```sh
tree-sitter generate && tree-sitter test -p .
tree-sitter parse -p . -q ../../examples/*.fitd   # prints nothing when every file parses
```

## Neovim (0.11+)

No plugin needed: build the parser into the runtime path and start highlighting on the filetype.

```sh
mkdir -p ~/.local/share/nvim/site/parser ~/.local/share/nvim/site/queries/fitd
cc -shared -fPIC -O2 -I src src/parser.c -o ~/.local/share/nvim/site/parser/fitd.so
cp queries/highlights.scm ~/.local/share/nvim/site/queries/fitd/
```

```lua
vim.filetype.add({ extension = { fitd = 'fitd' } })
vim.api.nvim_create_autocmd('FileType', { pattern = 'fitd', callback = function() vim.treesitter.start() end })
vim.lsp.config('fitd', { cmd = { 'fitd', 'lsp' }, filetypes = { 'fitd' }, root_markers = { '.git' } })
vim.lsp.enable('fitd')
```

## Helix (25.07+)

Build the parser into the user runtime, the same way as for Neovim (`hx --grammar build` would also try to fetch and build every other grammar Helix knows):

```sh
mkdir -p ~/.config/helix/runtime/grammars ~/.config/helix/runtime/queries/fitd
cc -shared -fPIC -O2 -I src src/parser.c -o ~/.config/helix/runtime/grammars/fitd.so
cp queries/helix/highlights.scm ~/.config/helix/runtime/queries/fitd/
```

In `~/.config/helix/languages.toml` (give `command` a full path if `fitd` is not on `PATH`):

```toml
[[language]]
name = "fitd"
scope = "source.fitd"
file-types = ["fitd"]
comment-token = "#"
indent = { tab-width = 2, unit = "  " }
language-servers = ["fitd"]

[language-server.fitd]
command = "fitd"
args = ["lsp"]
```

`hx --health fitd` should then tick the language server, parser, and highlight queries. Some distributions (Arch among them) install the binary as `helix` instead of `hx`.
